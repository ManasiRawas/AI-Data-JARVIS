# AI Data Analyst JARVIS

### Interactive Data Analytics Dashboard Using Python

AI Data Analyst JARVIS is a web-based analytics application that allows users to upload CSV datasets and explore them through automated statistical summaries, missing-value analysis, and interactive visualizations.

## Features

- CSV dataset upload
- Dataset preview
- Automatic row and column identification
- Missing values analysis
- Interactive Plotly visualizations
- Gender distribution analysis
- Education level distribution
- Experience distribution
- Job change distribution
- Descriptive statistical summaries
- CSV download

## Technology Stack

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Git and GitHub
